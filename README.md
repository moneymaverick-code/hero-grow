# 영웅 성장기 (가제)

숲속 옛 폐허에서 전사나 마법사를 키우는 방치형 RPG예요.
영웅은 넓은 들판을 돌아다니며 몬스터를 알아서 잡아요.
레벨도, 단계도 끝이 없어요. 몬스터와 대장도 끝없이 세져요.
장비를 모으고, 소환수와 같이 싸우고, 탈것을 타고 달려요.
게임을 꺼 둔 동안에도 보상이 쌓여요(최대 12시간).

> 게임 코드는 이 저장소에 없어요.
> 여기는 설치 파일을 받는 곳이에요.
> 진짜 돈 결제와 광고는 없어요. 금화·보석은 게임 안에서만 써요.
